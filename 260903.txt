변수 <-> 상수

-변수의 이해
값을 지정해도 수정이 가능함
변수의 종류: 무자, 숫자, 계산식, 클래스, ...
*기본형(실제 데이터를 메모리에 저장)
=>
정수형: byte(1byte), shot(2byte), int(4byte), long(8byte)
실수형: float(4byte, 소숫점 7자리), double(8byte, 소수점 15자리)
문자형: char(2byte, unicode,'문자')
문자열: string("문자열")
블리언형: boolean(1bite, True/False)

*참조형(실제 데이터가 아닌 객체의 주소를 저장)
=>
문자열 참조
배열 참조
크래스 참조
인터페이스 참조
예시: int(자료형) exam(변수 이름);

-변수는 값을 저장할 때 값을 초기화 시켜야함
가끔씩 쓰레기 값을 가질 수 있음
예시: int exam = 1000, exam2 = 2000;

System.out.println(price, sale);
=> 이 출력함수에서는 변수를 하나만 가져올 수 밖에 없음
쉼표 대신 +를 사용하면 더 가져올 수 있음
System.out.println(price + sale);
=> 다 더해지니까
System.out.println(price+ "," + sale);
=이러면 각 값을 가져올 수 있음
------------------------------------------------------------------------------------
System.out.println(1+"합계구하기"+2+3);
=>출력함수에서는 괄호 안 숫자를 계산하여 내보내는게 맞지만
문자/문자열("")이 들어가는 순간 그냥 출력해버림

-상수의 이해
상수: 리터럴
final(상수 예약어) int EXAM = 1;
상수를 쓸대 상수 이름을 대문자로 써주는게 약속(소문자도 가능하긴 함)

-식발자
사용 가능한 문자: 영어, 숫자, 언더바, 달러기호
불가: 숫자로 먼저 시작한 경우
대소문자 구분함 
예약어 사용 금지

자바의 명명 규칙
낙타 표기법: is*H*amburger
클래스 이름의 첫 글자는 대문자
의미있는 이름 사용
상수는 대문자

*리터럴*
값 자체를 의미하는 표현

-정수 리터럴
10진수: 일반적인 정수 표기법
표시 기호X
예시: 10, 

16진수: 16진수 A(10진수로 10)
예시: 0xA
표시 기호: 0x 또는 0X

*2진수: 0b or 0B 2진수 1010(10진수로 10)

*long 자료형: 숫자 뒤에 L 또는 l
예시: 10L
long 형태로 지정된 정수 10

*지수 자료형: 지수 자료형임을 의미(e1 = 10^1)
예시: 2.4124e1

*float자료형: 플롯 자료형임을 의미
예시: 3.14F

*double: 더블 자료형임을 의미
예시: 3.14D


*이스케이프 시퀀스
\n: 줄바꿈
\t: tab(  )
\": 쌍따옴표 출력
\': 따옴표 출력
\\:: \ 출력
\uXXXXX: 유니코드로 출력(예시: \u0041)


형 변환: 하나의 자료형을 다른 자료형으로 변환하는 것을 의미

강제 형 변환: 큰 자료형을 작은 자료형으로 변환 할때
double doubleValue = 3.31;
예시: int intValue = (int)[강제 형 변환]doubleValue;

print():줄 바꿈X[print()를 10개, 300개를 써도 줄 바꾸지 않고 가로로 이어짐 ]
