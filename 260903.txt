변수 <-> 상수

-변수의 이해
값을 지정해도 수정이 가능함
변수의 종류: 무자, 숫자, 계산식, 클래스, ...
*기본형(실제 데이터를 메모리에 저장)
=>
정수형: byte(1byte), shot(2byte), int(4byte), long(8byte)
실수형: float(4byte, 소숫점 7자리), double(8byte, 소수점 15자리)
문자형: char(2byte, '문자')
블리언형: boolean(1bite, True/False)

*참조형(실제 데이터가 아닌 객체의 주소를 저장)
=>
문자열 참조
배열 참조
크래스 참조
인터페이스 참조
예시: int(자료형) exam(변수 이름);

-변수는 값을 저장할 때 값을 초기화 시켜야함
가끔씩 쓰레기 값을 가질 수 있음
예시: int exam = 1000, exam2 = 2000;

System.out.println(price, sale);
=> 이 출력함수에서는 변수를 하나만 가져올 수 밖에 없음
쉼표 대신 +를 사용하면 더 가져올 수 있음
System.out.println(price + sale);
=> 다 더해지니까
System.out.println(price+ "," + sale);
=이러면 각 값을 가져올 수 있음
------------------------------------------------------------------------------------
System.out.println(1+"합계구하기"+2+3);
=>출력함수에서는 괄호 안 숫자를 계산하여 내보내는게 맞지만
문자/문자열("")이 들어가는 순간 그냥 출력해버림
