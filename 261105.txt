-public 접근 제한자
가장 개방적인 접근 권한을 제공하는 접근 제한자

-default 접근 제한자
같은 패키지 안에서만 접근 가능
다른 패키지에선 접근 불가

-protected 접근 제한자
같은 패키지 안에서는 접근 가능하고

-private 접근 제한자
가장 강한 제한을 가짐-> 캡슐화
다른 패키지, 같은 패키지에서도 접근 불가

getter, setter를 사용하여 데이터를 보호하는 것이 캡슐화

private 변수에서 final을 쓰면 상수로 바뀜 이후에 생성자를 써주면 오류가 사라짐

게터와 세터
읽기 전용과 쓰기 전용 변수 생성 가능

-접근제한자
필드는 기본적으로 private로
외부 접근이 필요한 경우에만 public메서드(gettter, setter)를 제공해야한다
세터에는 반드시 유효성 검사 조건을 추가하는 것이 좋다
읽기 전용 변수는 final로 선언하고, 세터를 만들지 않아야 한다

-static 멤버
클래스 전체에서 공유하는 변수나 메서드를 만들 때 사용하는 예약어
static으로 선언된 변수는 클래스가 메모리에 로딩될 때 한 번만 생성
