-static 클래스 전체에 공유하는 변수나 메서드를 만들 때 사용

static으로 생성된 메서드는 객체를 생성하지 않고도 클래스 이름으로 접근 가능

package sec02.exam07;

class DonutInf{
	static String phoneNumber = "01-1234-5678";
	static void callShop() {
		System.out.println("도넛가게: "+phoneNumber);
	}
}


public class StaticMethodExample {
	public static void main(String[] args) {
		DonutInf.callShop();
	}

}

원래 new 해서 객체를 생성해서 사용하는데 이건 그냥 메인 클래스로 불러와서 바로 사용 가능함.

static멤버 특징
-인스턴스 변수에 접근 불가

-static final 변수
final: 변수를 상수로 바꾸어주는 예약어

static + final은 값이 바뀌지 않고, 객체 없이 접근 가능한 값을 만들 수도 있다.

+장점
한곳에서 값으 관리할 수 있어 일관성 유지가 좋고
가독성이 좋아지며,
실수 방지에 용이하여 안전성이 좋아진다.

불변 객체
불변 객체 String 
문자열이 한 번 생성 후에 변경되면 프로그램에 문제가 생길 수가 있음
그렇기에 다른 변수들(int, double)과는 다르게 불변 객체로 설계되어있다.

-예외 처리
연산 작업이나 클래스에서 주소값 불러올 때
근데 원래 주소가 없거나 수치가 없는 계산을 하면 오류임
그때 프로그램에 알려주는 것이 예외처리
자바에서 데이터 베이스를 쓸때 db하고 연결해주는 파일이 존재 근데 그 파일이 없거나 충돌이 났을때 오류처리해주는게 예외처리

package sec02.exam09;

import java.util.Scanner;

public class DonutOrderWithException {
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		
		String[] donutMenu = {"", "초코", "레몬", "딸기"};
		int[] donutPrice = {0,2000,2200,2100};
		
		System.out.println("도넛 주문 시스템");
		System.out.println("1: 초코(2000원)");
		System.out.println("2: 레몬(2200원)");
		System.out.println("3: 딸기(2100원)");
		System.out.println("번호 입력: ");		
		
		try {
			int menuNum = sc.nextInt();
			String donut = donutMenu[menuNum];
			int price = donutPrice[menuNum];
			System.out.println(donut+"을 선택하셨습니다.");
			System.out.println("결제금액: "+price+"원");
		} catch (ArrayIndexOutOfBoundsException e) {
			System.out.println("메뉴번호 오류! 1~3 중에 선택");
		} catch (Exception e) {
			System.out.println("입력 오류! 숫자를 입력");
		} finally {
			System.out.println("도넛 가게 이용에 감사드립니다.");
			sc.close();
		}
		
	}
}

try{}의 안에 있는게 발생했을 때
catch (ArrayIndexOutOfBoundsException)은 배열 안에 인덱스의 범주를 벗어난 예외 처리가 발생했을 때 출력
catch (Exception)은 그냥 다른 문자를 입력했을 때 만약 배열이 int인데 String을 넣었을 때 예외 처리 발생하면 출력
finally 위에 catch가 다 끝났을 때 finally로 무조건은 아닌데 여기는 끝나면 끝났다고 알려줘야하니까 씀


package p20261112;

class Student{
	static String school="폴리텍대학";
	String name;;
	Student(String name){
		this.name = name;
	}
}

public class MainTest {
	public static void main(String[] args) {
		Student s1 = new Student("철수");
		Student s2 = new Student("영희");
		System.out.println(s1.school);
		System.out.println(s2.school);
		System.out.println(Student.school);
	}
}
