-예외 처리
예외: 정상적인 흐름에서 벗어나는 상황
예외를 처리하지 않으면 프로그램은 종료되며, 사용자에게 오류메시지를 출력함
따라서 예외 상황을 예측하고 적절히 처리할 필요가 있음 

=체크 예외
컴파일 시점에서 반드시 처리해야 하는 예외
*아래는 자바 주요 체크 예외
IOException == 파일 입출력, 네트워크 통신 등의 입출력 잡업에서 문제가 발생하는 경우
SQLException == 데이터베이스 연결 및 처리 작업 중, 잘못된 SQL 구문 실행, 드라이버 오류, 연결 실패 등에서 발생
ClassNotFoundException == 클래스를 동적으로 로드하려 했으나, 해당 클래스를 경로에서 찾지 못할 때 발생
InterruptedException == 스레드가 sleep(), join(), wait() 등으로 대기 중일 때, 다른 스레드에 의해 중단 신호를 받았을 때 발생
Exception == 자바에서 복구 가능한 모든 예외의 최상위 클래스로 일반적인 예외 처리를 위해 포괄적으로 사용하며, 항상 마지막에 작성
