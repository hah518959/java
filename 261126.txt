-객체 배열과 열거형

=>객체 배열 선언과 생성
* 객체 배열: 객체의 주소를 저장하는 구조
* 같은 종류의 객체를 효율적으로 관리함
* 배열을 선언하고, 배열의 크기를 지정해 생성

=> 객체 배열의 사용
* 각 객체에 반복문으로 접근할 수 있으므로, 같은 종류 데이터의 일괄 처리 가능

-열거형
* 서로 관련 있는 고정된 값을 하나의 묶음으로 정의하는 특별한 자료형
*

=>열거형에서 사용 가능한 기본 메서드
* name(): 열거 상수의 이름을 문자열로 반환
* ordinal(): 해당 열거 상수가 선언된 순서를 반환
* values(): 해당 열거형에 정의된 모든 값을 배열로 반화 

=>열거형 사용시 이점
* 가독성 코드 안전성 향상 
* 유지보수에 용이
* 객체처럼 사용가능 필드 메서드 추가가 가능해 각 상수에 대한 의미가 더 풍성해짐
